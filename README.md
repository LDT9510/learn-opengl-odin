# Learning OpenGL

- Following tutorial at: https://learnopengl.com/
- Implemented up to: `Gamma Correction` chapter.
- Developer UI using ImGUI.
- Tested on Windows 11 only.
- Exercises where implemented in a single file for exercise up to `Framebuffers` section.
- Resource system with code generation.
- Run and build with `run.bat res && run.bat`, read the script for aditional options. Resource gen script requires python
  (`run.bat` assumes `uv` installed, needs to be ran when resources are updated)
- **No AI** was used.
